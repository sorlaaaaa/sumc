# 素材清单与替换说明

《选择你的川传生活》当前**全部图片均为占位**（CSS 色块剪影 + 槽位标注），你提供素材后按下表替换即可，**无需改代码逻辑**。

---

## 一、如何运行 / 预览

纯静态，无构建、无依赖：

- 直接双击 `index.html` 用浏览器打开即可玩。
- 或本地起个静态服务器（任意一种）：`python -m http.server 8080`，访问 `http://localhost:8080`。
- 移动端真机预览建议走静态服务器 + 手机同网访问，或部署到公众号/迎新站静态目录。

---

## 二、目录结构

```
sumc/
├─ index.html        页面骨架（占位槽位以 data-slot 标注）
├─ css/style.css     全部样式（配色、胶片/监视器母题、响应式）
├─ js/data.js        文案/点位/属性/结局/校友数据（改内容在这里）
├─ js/app.js         交互逻辑（一般不用改）
└─ assets/           素材目录（你提供后放入）
   ├─ maps/          两张校园平面图
   ├─ scenes/        各建筑内景 / 空镜图
   ├─ chars/         人物立绘 / 吉祥物
   ├─ alumni/        校友照片
   └─ bg/            开场背景、结局底图
```

## 四、如何替换（两种方式，任选）

**方式 A（推荐）：直接改 HTML/CSS 背景**

把图片放到 `assets/` 后，找到对应槽位元素，替换成 `<img>` 或设置 `background-image`。例如：

```css
#mapBg { background: url(../assets/maps/east.png) center/cover no-repeat; }
```

**方式 B：给数据层加图片字段**（已预留 `data-slot` 便于脚本批量加载，可后续让开发接上）。

## 五、点位坐标调整（换真地图后必看）

在 `js/data.js` 的 `LOCATIONS` / `EASTER_EGGS` 中，每个点有：

```js
pos: { x: 50, y: 86 },   // 百分比坐标，以地图左上角为原点
```

换图后把每个 `pos` 对齐到你图上建筑的实际位置即可。正式点 17 个 + 彩蛋 4 个（东区 12 + 4、西区 5）。

## 六、内容修改指引（都在 `js/data.js`）

- **改属性数值 / 对话 / 贴士**：改 `LOCATIONS` 各字段（`desc` 空镜、`encounter` 遭遇、`choice` 选择、`flatAttr` 无选择时的属性、`tipIds` 贴士）。
- **改贴士库**：改 `TIPS`。
- **改结局 / 校友**：改 `ENDINGS`、`ALUMNI`。
- **改每局行动点 / 结算门槛**：改 `GAME`。
